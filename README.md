🍰 Sugar Bliss – Bakery Website

Sugar Bliss is a responsive bakery website developed using HTML, CSS, and JavaScript. It provides an attractive and user-friendly platform to explore bakery products and access different bakery services.

✨ Features

- Attractive and user-friendly homepage.
- About Us section introducing the bakery.
- Bakery menu to explore available products.
- Online order page.
- Table reservation page.
- Contact page for customer enquiries.
- Responsive website design.
- Interactive elements using JavaScript.

🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Interactive functionality.
